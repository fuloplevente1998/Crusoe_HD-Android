# Robinson Crusoe – saját Android-motor 0.6.0 alpha

Saját motoros Android-próbaváltozat, Android 8.0+.

**[APK letöltése – 19,2 MB](https://raw.githubusercontent.com/fuloplevente1998/Crusoe_HD-Android/apk-download-native-0.6.0/Crusoe-Native-0.6.0.apk)**

- Érintőkaros vadászat és kókuszdobálás: bal/jobbra szög, fel/le erő és így röppálya/távolság.
- Külön lövés/dobás gomb, kétujjas használattal. A kar felengedése nem lő, a beállítás megmarad.
- Horgászat: érintőkaros horogmozgatás, külön megakasztás, majd felhúzás a felszínre.
- Új kókusz-minijáték: két találat/kókusz, legalább öt kókusz legfeljebb tíz dobásból. Az első találat 11 másodpercig érvényes.
