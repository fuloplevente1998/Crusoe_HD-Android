# Robinson Crusoe – saját motoros Android 0.5.0 alpha

[APK közvetlen letöltése](https://raw.githubusercontent.com/fuloplevente1998/Crusoe_HD-Android/apk-download-native-0.5.0/Crusoe-Native-0.5.0.apk) · [Tesztkiadás](https://github.com/fuloplevente1998/Crusoe_HD-Android/releases/tag/native-v0.5.0-alpha)

Android 8.0+. Saját Android/Canvas-motor, natív ikonos tarisznya és készítés. A korábbi saját motoros alpha fölé telepíthető. Az eredeti Java ME játék és J2ME Loader nem fut ebben az APK-ban.

Ez fejlesztői tesztkiadás. A teljes küldetéslánc, árapály/időjárás és befejezés hiányzik; néhány grafika és szabály közelítő. Fizikai telefonos teljesítményteszt még nincs. Helyben 11 Android/Skia-teszt és 280 motorfeltétel átment.

Az APK az önálló működéshez szükséges játékadatokat tartalmazza. A forrás, a generált grafikák és a részletes korlátok a [fejlesztési ágon](https://github.com/fuloplevente1998/Crusoe_HD-Android/tree/feat/native-engine-v01/native) találhatók.
